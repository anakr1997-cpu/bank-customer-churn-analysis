# Bank Customer Churn Analysis | Python

## Project Overview

Completed a Python-based data preparation and exploratory analysis project examining bank customer information and churn. The project focuses on cleaning inconsistent data, combining datasets, and preparing customer information for analysis.

## Tools & Skills

- **Python:** Data processing and analysis
- **Pandas:** Data cleaning, merging, and feature engineering
- **NumPy:** Numerical operations
- **Seaborn:** Exploratory data visualization

## Project Workflow

### 1. Data Preparation
- Imported customer and account information from Excel worksheets.
- Combined datasets using customer identifiers.
- Identified and addressed duplicate records and missing values.

### 2. Data Cleaning
- Converted currency-formatted salary and balance values into numeric data types.
- Addressed invalid salary values using median imputation.
- Standardized inconsistent categorical information.

### 3. Exploratory Data Analysis
- Examined customer characteristics and churn patterns.
- Created visualizations to explore relationships between customer attributes and churn.
- Used descriptive statistics to better understand the dataset.

### 4. Feature Engineering
- Created additional financial features, including a balance-to-salary ratio.
- Prepared categorical variables for further analysis.

## Project Highlights

- Applied Python and Pandas to clean and prepare customer data.
- Resolved data quality issues involving missing values, duplicates, and inconsistent formatting.
- Combined customer and account records into an analytical dataset.
- Explored customer churn using descriptive statistics and visualizations.

## Project Files

- `Bank Customer Churn.ipynb` — Jupyter Notebook containing the Python analysis

## Data Source

Educational bank customer churn dataset used for a guided analytics project. The source dataset is not redistributed in this repository pending confirmation of sharing permissions.

## Project Scope

This project focuses on data cleaning, exploratory analysis, and feature engineering. It does not include training or evaluating a churn prediction model.
